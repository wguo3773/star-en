STAR-EN Overview

Download main figure ↓

STAR-EN is a Python-based framework for multi-omics prediction and risk stratification in underrepresented populations. It brings together source-anchored elastic-net transfer learning (SAT-EN) and layer-weighted source-anchored transfer learning (LSAT-EN). Both approaches adapt information from a larger source cohort to a smaller target cohort. SAT-EN regularizes target deviations from a source anchor, while LSAT-EN allows source-borrowing strength to vary across molecular layers. Logistic and Cox formulations address fixed-horizon binary outcomes and censored time-to-event outcomes, respectively.

Held-out predictions can support downstream risk grouping, restricted mean event-free time comparisons, and correlations with Hallmark pathway scores and miRNA abundance. STAR-EN 0.2.0 includes SAT-EN and LSAT-EN estimators, binary and Cox prediction, and functions for both risk/RMST and pathway/miRNA figures. See the four worked examples.

GET STARTED

Installation

Install the Python package, check the import, then choose a binary or survival example.

1. Create an environment

Python 3.10 or later is required. Use an isolated environment so dependency versions do not affect other projects.

python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip

2. Install STAR-EN

python -m pip install "star-en[analysis,survival] @ git+https://github.com/wguo3773/star-en.git"

The analysis extra installs lifelines and matplotlib for both downstream figure types. The survival extra adds scikit-survival for C-index and IPCW AUC. This command installs the complete STAR-EN package from GitHub, with both methods. The repository and Python distribution are STAR-EN. Source archive ↓ · Wheel ↓.

3. Verify the installation

python -c "from staren import SATBinaryCV, SATCoxCV, LSATBinaryCV, LSATCoxCV; print('STAR-EN import successful')"

Expected confirmation:

STAR-EN import successful

4. Run an example

tar -xzf star_en-0.2.0.tar.gz
cd star_en-0.2.0

Troubleshooting

If a Git installation fails, check git --version. If the survival extra fails, check your Python/platform compatibility with scikit-survival installation instructions. Binary/Cox fitting can be installed without optional survival evaluation tools using python -m pip install "git+https://github.com/wguo3773/star-en.git".

BREAST CANCER

TCGA-BRCA

Source: older patients, using separate age cutoffs of ≥50, ≥55, or ≥60 years. Target: patients aged <50 years. Original manuscript prediction examples use OS; the downstream RSF examples use PFI.

PEDIATRIC AML

TARGET-AML

White source cohort → Black target cohort; primary specimens only. Saved examples use mRNA and miRNA. The illustrated endpoint is EFS, not PFI.

GDC project ↗TARGET AML study ↗

TARGET-AML is a TARGET project, not TCGA-AML. Use the dataset's documented EFS/OS definitions and consistent time units; do not substitute EFS for PFI.

Reading the outputs

AUC: discrimination between event and event-free patients. IPCW AUC accounts for censoring; it is not calibration.

BACC: the mean of sensitivity and specificity at the stated cutoff. Different cutoff rules produce different BACC values.

RMST: area under the Kaplan–Meier curve through the horizon. A positive low-minus-high difference means longer restricted mean event-free time in the low-risk group.

Pathways: correlation with predicted risk, not proof of pathway activation or independent association with observed outcomes. Report multiple-testing results and patient overlap.
